Les quatre décisions, à l'essai

1 · Le premier écran

Au premier lancement, un choix à deux cartes (écran ci-dessous), puis l'application se souvient. Le sélecteur de l'en-tête reste là pour changer d'avis.

Recommandé : choix puis souvenir

2 · La palette

Une seule palette : l'emblème et les mots disent l'univers. Ou un accent or plus présent pour le logement, sur les badges et les prix.

Recommandé : palette unique

3 · Les rôles dans les barres

Un contrôleur voit Contrôle dans Voyager ; un agent d'agence voit Annonces dans Me loger. Les autres ne voient rien de plus.

4 · Les libellés

Des verbes, qui disent ce que l'on vient faire — ou des noms de domaine.

Recommandé : les verbes

Le parcours, écran par écran

Faites défiler horizontalement. Ces écrans sont fixes ; seul le téléphone du haut réagit.
